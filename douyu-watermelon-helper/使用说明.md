# 斗鱼合成大西瓜自动落点助手（实验版）

这是一个 Chrome / Edge Manifest V3 浏览器扩展，不是油猴脚本。

目前没有拿到真实游戏运行中的画布和接口：本地浏览器访问直播间时资源加载失败；你补充的截图是开局菜单。因此本版本采用截图识别与鼠标投放，需要首次校准。**尚未在斗鱼实际对局中验证，不能承诺装上即可正确识别或必胜。**

## 安装

1. 解压 ZIP，保留包含 `manifest.json` 的整个目录。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展”，选择含 `manifest.json` 的目录。
4. 打开斗鱼 6657 直播间，打开合成大西瓜，**自行决定并手动开始一局**。截图中的开局按钮显示消耗 2 枚金币；扩展不负责开局。
5. 将整个棋盘放在可见区域，点击扩展图标，打开助手窗口，再点击“连接直播间”。

浏览器会显示调试提示，这是 `debugger` 权限的正常提示。扩展仅对你点击图标选定的斗鱼标签页使用截图、视口信息和鼠标输入；源码没有网络请求、账号读取或数据上传。此权限本身能力较广，请在使用后断开连接。若 DevTools 或另一个扩展占用调试连接，请先关闭它。

## 首次校准

校准前必须进入实际对局，不能在开局菜单操作。

1. **棋盘**：从结束线到容器底部，框选内部区域，排除边框、分数、人物、任务图标和按钮。完整棋盘须在当前屏幕内。
2. **待投水果**：框选这一次将落下的水果所在位置，四角保留空白，留出不同水果尺寸变化的空间。不要选“下一个”预览、文字或装饰图案。若待投水果会随鼠标横移，框选区域须覆盖其整个移动范围，并保持四角是空白。
3. **背景色**：点击棋盘空白背景。你截图里背景有粉色、橙色、紫色渐变，应在实际棋盘的不同高度采集空白色，最多 6 处。不要取到水果、阴影、文字或结束线。
4. **投放高度**：在棋盘内点一个正常手动投放的位置。自动运行会在这一高度改变横坐标并点击。
5. **检测预览**：橙色圈应对应棋盘上的真实水果；绿色圈表示与待投水果相似；蓝色圈应对应待投水果，红线为落点。检查漏识别和误识别，正确后勾选确认，再点“开始自动”。

背景变色、窗口大小或页面位置变化时，重新截图并校准。原始截图只保存在助手页面内存里，不写入文件。

## 自动运行行为

- 通过圆形轮廓、颜色直方图及尺寸推测同类水果，没有使用游戏内部等级数据。
- 估算垂直下落的首个碰撞对象，优先直接合并可触及的同类水果，其次选择较低位置。
- 等待棋盘画面稳定后再投放，默认最短间隔为 1.8 秒。
- 标签页切走、浏览器最小化、滚动、视口改变、截图失败、待投水果消失、棋盘长时间运动、投放后没有变化或水果接近校准结束线时暂停。
- 点击“暂停”、关闭助手窗口，或关闭浏览器的调试提示可停止。Esc 仅在助手窗口获得键盘焦点时有效。
- 不主动寻找开局、重开、道具或兑换按钮；但截图识别不能可靠辨认所有弹窗，校准错误或游戏弹窗可能导致误点。出现异常请立即暂停。

依据提供的规则，游戏有 11 级水果、触线结束、10 分钟无操作自动结束，也不能同时开多种游戏。扩展不修改这些规则、分数、金币或奖励；只能尝试正常投放。

## 当前限制与调参

- 视觉同类判断可能混淆相似水果；尚未建立该游戏的完整 11 级映射，也无法可靠辨认最高级西瓜是否还能合并。
- 规划使用垂直碰撞近似，没有模拟滚动、弹跳、摩擦与完整连锁反应。
- 渐变、纹理、半透明水果、粒子动画、遮挡和弹窗可能影响轮廓识别。如果无法让预览圈与实际水果对应，请不要开始自动。
- 大片背景被圈出：增加背景样本，或略提高背景色容差。
- 水果被当作背景：避免取到与水果相同的颜色，或降低容差。
- 小水果漏掉：降低最小半径；文字或小图标被圈出：缩小棋盘区域或提高最小半径。
- 游戏不响应输入时，助手会在检测到棋盘无变化后停止；不要关闭此检查来强行连点。
- 建议先运行几次投放并观察，再决定是否继续。没有真实对局证据前，不宜无人看管运行。

## 文件与验证

- `background.js`：绑定目标标签页、截图、鼠标输入、暂停边界。
- `engine.js`：水果轮廓识别、同类判断、落点规划。
- `panel.html` / `panel.css` / `panel.js`：校准与启停面板。
- 无第三方依赖，无远程代码。

交付前通过 16 项测试，使用模拟水果图像验证识别和策略，并使用浏览器 API 模拟验证输入边界、暂停、滚动和标签页切换。校准面板也在本地模拟画面中完成了框选、取色、预览、连续投放 9 次及暂停流程，控制台无错误。这些测试不等于真实游戏兼容性测试。要进一步定制，需要实际对局完整截图或游戏 iframe 的 src 地址。
