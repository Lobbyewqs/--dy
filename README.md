# dy合成大西瓜助手 v0.2.0

提供油猴脚本和 Chrome / Edge 扩展两种方式，任选其一。升级前请停用旧版，避免两个助手同时操作。

## 油猴脚本

1. 在 Chrome / Edge 中安装并启用 Tampermonkey（油猴）。
2. 新建脚本，将同目录外的 `douyu-watermelon-helper-v0.2.user.js` 全部内容粘贴进去并保存；也可通过油猴打开该文件安装。
3. 允许脚本在dy游戏 iframe 内运行，保留 `@sandbox raw` 和 `@grant none`，以便访问游戏场景。
4. 在直播间打开合成大西瓜。脚本显示右下角“大西瓜助手 0.2”面板。
5. 由你手动开局，然后点击面板“自动”。点击“暂停”停止；游戏获得键盘焦点时也可用 F8 启停、Esc 暂停。

油猴通常只在页面或 iframe 加载时运行脚本。正在进行的游戏请不要为安装脚本刷新页面，刷新可能结束本局；可在下次手动打开游戏时使用。若当前局希望直接连接，可使用下面的扩展方式。

## Chrome / Edge 扩展

1. 解压 `douyu-watermelon-helper-v0.2.0.zip`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。
4. 保持斗鱼直播间为当前标签页，点击扩展图标，打开助手面板。
5. 点击“连接游戏”，确认能显示分数、待投等级和水果示意图。手动开局后点击“开始自动”。已经开局时可直接连接，无需刷新。
6. 通过“暂停”“断开连接”或关闭助手窗口停止。使用结束后可停用扩展。

扩展使用 `activeTab` 和 `debugger` 权限，浏览器会提示调试连接。权限用于读取当前直播间游戏 iframe 的 Cocos 场景，并调用正常投放方法。打开该标签页的开发者工具可能导致调试连接断开；重新连接后需再次手动启动助手。

## 自动选择落点

- 读取当前可见水果的真实等级、位置、碰撞半径和运动状态，免去旧版框选校准。
- 优先选择能触及的同级水果，评估附近连锁合成与堆叠高度；最高为 11 级。
- 等待连续稳定样本后投放，默认最小间隔 1.6 秒；扩展可调整为 1.2～8 秒。
- 投放前再次核对水果 ID 和本局编号；通过游戏原有 `dropCurrentFruitAt` 流程投放，等待游戏确认，防止重复投放。
- 本局结束、切换标签页、游戏隐藏、弹窗、道具状态、长时间无响应或没有安全落点时暂停。恢复后需手动启动。

助手只控制本局水果投放。开局、复活、道具购买、抽奖和下一局均由你操作。不会自动修改分数、币数、物理参数或未来水果队列。

面板“导出”可保存当前场景 JSON，包含水果、边界、分数等排查数据，不包含账号、令牌或未来水果。数据在本地生成，助手没有上传接口。

## 验证与限制

本版本根据实际页面公开加载的 Cocos 3.8.6 游戏代码（业务文件 `assets/main/index.c3dcd.js`）适配。完成 29 项模拟运行环境测试，覆盖场景读取、落点规划、11 级上限、边界、重复投放、取消、弹窗和本局切换。完整油猴脚本在本机模拟页面完成 13 次投放，暂停后计数保持不变，并验证了画布延迟加载。网页实测了一次普通鼠标投放，分数从 8 增至 11；新版脚本接入真实场景后的连续自动运行尚未实测。

落点与连锁使用几何近似，未完整模拟 Box2D 的滚动、反弹和挤压，因此不能保证最高分或合成大西瓜。游戏升级后若接口变化，可能无法连接或会暂停。若没有显示真实分数/等级，先停止助手，检查游戏是否已经加载、是否为普通合成玩法，以及油猴是否允许在 iframe 的页面环境运行。

两个版本都默认暂停，不会跨局自动续玩。页面切到后台可能触发游戏自身的结束规则，请保持游戏可见。
