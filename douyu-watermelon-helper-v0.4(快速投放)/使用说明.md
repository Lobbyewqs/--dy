# 斗鱼合成大西瓜助手 v0.4.0

## 升级与安装

先停用 v0.3 及更早的助手，避免同时投放。油猴与扩展任选一种，保留旧版文件供回退。

- 油猴：在 Chrome / Edge 的 Tampermonkey 中新建或更新脚本，粘贴包内 `douyu-watermelon-helper-v0.4.user.js` 并保存。允许在斗鱼游戏 iframe 中运行，保留 `@sandbox raw` 和 `@grant none`。下次打开游戏时加载，手动开局后点击“自动”。进行中的一局请不要为安装而刷新页面。
- 扩展：解压 `douyu-watermelon-helper-v0.4.0.zip`，在 `chrome://extensions` 或 `edge://extensions` 启用开发者模式，加载包含 manifest.json 的目录。已有扩展可更新目录后点重新加载。在直播间点击扩展图标，连接游戏，手动开局后点击“开始自动”。已开局可直接连接，无需刷新。

扩展的 activeTab/debugger 权限用于读取当前游戏 iframe 场景并调用普通投放方法；浏览器会显示调试连接。开发者工具可能使连接断开。Codex 内置浏览器不能直接安装这些扩展，请在 Chrome / Edge 使用。

## 新版节奏

- 默认使用“动态短期预测”，不再要求所有水果静止，也不等待上一水果标记清除。
- 每轮结束后约 150 毫秒再次读取场景。默认最短投放间隔 0.65 秒；可在面板启动前调整为 0.45～8 秒。实际间隔还取决于游戏冷却、横移动画、网络、规划和可用落点，不保证固定速率。
- 游戏未就绪、投放确认中或合成队列处理中仍会等待。旧落点因新合成、明显偏离或过期而失效时，下一轮重算。
- 减少计算：最多 6 个短期候选、2 个最终候选；时间预算约 140 毫秒，每条预测约 18 毫秒软上限。超时则明确使用保守几何落点，该回退未通过完整物理检查。
- 可选择“保守几何（快速）”；这是依据当前速度外推的单步策略，区别于 v0.2 的静态连锁估算。切换策略先暂停，再手动启动。

## 预测修正

模拟包含投放前 0.12～0.22 秒的横移动画，动画期间原棋盘继续运动；使用当前 dropY、位置、线速度、角速度和休眠状态，开启连续碰撞。没有明确休眠信息时，不再把“瞬时零速”误当成休眠。

预测重点为首次接触及其后约 0.32 秒，最多约 2 秒，不再依靠未知下一水果与远期连锁得分。最终候选分别测试左右约 4 像素偏移，同时改变摩擦、弹性和释放延迟。

面板显示最近可对照的“观测偏差”和样本数。按预测时间插值，与相同 ID 的真实水果比较位置；偏差变大时降低物理结果的评分权重。这是模型可信度反馈，不是在线训练，也不能保证预测变得精确。新计划会替换上一观察窗口，快速投放时往往只获得较早的轨迹样本。

## 暂停与边界

“暂停”或 Esc 停止；油猴 F8 启停。隐藏游戏、切换标签页、弹窗、道具状态、结束或断开连接时暂停。投放前核对本局与水果 ID，并在游戏执行环境再检查快照年龄和棋盘变化。一次投放收到确认前不再次投同一水果。

只控制本局普通水果投放；不自动开局、复活、购买、抽奖或重开，不改分数、币数、物理参数或未来队列。数据与依赖留在本地，无上传接口。

“导出”包含当前棋盘、最近计划、短期轨迹和观测偏差，不含账号或令牌。模型参数尚基于之前读取的公开游戏版本，游戏升级可能需要重新适配。

## 验证

见“验证报告.md”。本版尚未安装到真实斗鱼连续运行，不能据本机夹具推断实际得分或胜率。物理后端、调度、接触排序仍可能不同；更快投放也可能降低复杂局面的得分。原 v0.3 可回退。

安装无需 Node.js。复核时在本目录运行：

```powershell
node tests/run-tests.cjs
node tests/benchmark.cjs
```

基准使用本地模型与人工事件夹具，输出 tests/benchmark-results.json。参考数据为 tests/benchmark-reference-results.json。
